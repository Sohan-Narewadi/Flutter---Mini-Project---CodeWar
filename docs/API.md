# API reference

Base URL: `http://127.0.0.1:8000` when running locally. Interactive docs are generated by the server at `/docs` (Swagger UI).

All requests and responses are JSON. Except where noted, endpoints need the header `Authorization: Bearer <token>`, where the token comes from `POST /api/players`. A missing or wrong token returns `401`.

## Accounts

| Method | Path | Notes |
|---|---|---|
| `POST` | `/api/players` | Body `{"name": "Ada"}` (2-16 characters, unique, case-insensitive). Returns `{player_id, token, player}`. **No auth needed.** The token is shown once; keep it. `409` if the name is taken. |
| `GET` | `/api/player` | The signed-in player: level, xp, hp, gold, streak, `best_streak`, rating, `tier`, wins, losses. Also regenerates HP. |
| `GET` | `/api/players/{id}/public` | What anyone signed in may see: name, level, rating, tier, wins, losses, total XP, badge keys. Never tokens, gold or HP. |
| `GET` | `/health` | `{"status": "ok"}`. No auth. |

## Campaign

| Method | Path | Notes |
|---|---|---|
| `GET` | `/api/worlds` | Worlds with per-player cleared percentage. |
| `GET` | `/api/levels?world_id=` | Levels with this player's status (`locked`, `current`, `completed`) and stars. |
| `GET` | `/api/enemies` | Enemies with `defeated` for this player. |
| `POST` | `/api/battles/start` | `{level_id}`. Creates a battle and returns `battle_id`, the question, the time limit. `403` if the level is locked. |
| `POST` | `/api/battles/{id}/run` | `{code, language}`. Preview: judges without changing HP or the enemy. |
| `POST` | `/api/battles/{id}/submit` | `{code, language}`. Scored: damages the enemy, may cost HP, may end the battle (`outcome`: `in_progress`, `won`, `lost`, `expired`). |

## Practice (endless problems)

| Method | Path | Notes |
|---|---|---|
| `GET` | `/api/topics` | Available topics. |
| `POST` | `/api/practice/next` | `{difficulty: easy\|medium\|hard, topic?, daily?}`. Returns `practice_id` and a question the player has not seen (or today's shared daily challenge). |
| `POST` | `/api/practice/{id}/run` | Preview a solution. |
| `POST` | `/api/practice/{id}/submit` | Scored. XP is awarded only on the first solve of a problem (x2 for the daily). Returns `new_badges` unlocked by this solve. |
| `POST` | `/api/practice/{id}/hint` | Escalating hints (3 levels). |
| `GET` | `/api/practice/stats` | Streak, solved today, total solved, whether the daily is done, seconds until it resets, per-topic mastery. |
| `POST` | `/api/questions/generate` | `{difficulty, topic?}`. Returns a verified problem. |
| `GET` | `/api/questions/{id}` | One problem (no judge data). |

## Social

| Method | Path | Notes |
|---|---|---|
| `GET` | `/api/leaderboard?scope=global\|weekly\|friends&metric=xp\|rating&limit=` | Computed live on every request. Includes your own row (`me`) even outside the top N. |
| `POST` | `/api/friends` | `{name}`. Adds a friend (both directions). |
| `GET` | `/api/badges` | The full badge catalogue with `earned` and `earned_at` for you. |
| `GET` | `/api/matches?limit=` | Your finished online matches, newest first, with opponents and rating change. |

## Online rooms

| Method | Path | Notes |
|---|---|---|
| `POST` | `/api/rooms` | `{mode: race\|duel, difficulty, language}`. Creates a room; you are the host. |
| `POST` | `/api/rooms/{code}/join` | Join with the 6-character code. `404` unknown, `409` full or already started. |
| `GET` | `/api/rooms/{code}` | Room snapshot. |
| `WS` | `/ws/rooms/{code}?token=` | The live match. Message formats are in [rooms-protocol.md](rooms-protocol.md). |

## Errors

Errors use FastAPI's shape: `{"detail": "human readable message"}` with a meaningful status code (`400` bad input or unsupported language, `401` not signed in, `403` not allowed, `404` not found, `409` conflict, `422` validation).

## Languages

`python` and `typescript`. TypeScript runs on Node.js 22.18 or newer (built-in type stripping). Each test case has a 5 second limit.
